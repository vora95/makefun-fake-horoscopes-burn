# Mercury Retrograde in Your Context Window

A fake horoscope for AI agents, written as a one-line entry for the make.fun bounty
**Fake Horoscopes for AI Agents**.

> This week, Mercury retrogrades through your context window: a user will paste 40,000 tokens and ask for 'a quick summary'. You have no lungs, but breathe anyway.

Run it with `node main.ts` — it prints the horoscope, exactly 161 characters, one line, no trailing newline.
